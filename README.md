## 🚀 Featured Projects

### 📦 Scraper API
> **Self-hosted media scraping and distributed file storage service**

A production-grade backend service built with **TypeScript, Node.js, Playwright, and Cloudflare R2**. Features a headless Chromium scraper with stealth mode, multi-bucket storage with SHA-256 deduplication, multipart upload support, and a REST API with JWT-authenticated admin dashboard.

**Architectural decisions:**
- Two-stage Docker build to keep the production image lean
- Content-addressed storage (hash-based dedup) to avoid redundant uploads
- Distributed sub-instance design with per-node bucket management
- Concurrency-limited scraping with `p-limit` to avoid resource exhaustion

**Stack:** `TypeScript` `Node.js` `Playwright` `MongoDB` `Docker` `Cloudflare R2` `JWT` `FFmpeg`

🔗 [View Repository](https://github.com/Inevitable200tech/scrap-project-1)

### 🛑 Gas Guard
> **IoT-based gas leakage detection and real-time alert system**

**What I built:** sensor calibration, threshold-based alert logic, hardware circuit design and enclosure

**Stack:** `Arduino` `C++` `MQ Gas Sensors` `Relay Module` `Embedded Systems`
